# THDC Financial Analysis

Financial Performance Analysis & Business Insights of THDC India Limited using Power BI.

## Project Overview

An interactive Power BI dashboard developed to analyze the financial performance and key business indicators of THDC India Limited.

## Objectives

- Analyze financial performance across multiple years
- Track revenue and profit trends
- Analyze assets and borrowings
- Evaluate key financial ratios
- Analyze power generation performance
- Identify trends and business insights

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Analysis

- Revenue & Profit Analysis
- Asset & Borrowing Analysis
- Financial Ratio Analysis
- Power Generation Analysis
- Year-wise Trend Analysis

## Dashboard

The dashboard provides interactive visual analysis using KPIs, charts, tables and filters.
